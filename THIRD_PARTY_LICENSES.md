# Third-party material

- No third-party code is included: no libraries, no frameworks, no CDN scripts.
- No web fonts are bundled. The pages ask for a condensed display font, a sans-serif and a monospace font by name and fall back to the fonts installed on your system.
- Physical constants (CODATA values, exact SI definitions) and astronomical data are public reference values. Each experiment page lists the values it uses and where they come from in its last section.
- Development only (optional smoke test): `jsdom`, installed by `npm install`, MIT License. It is not part of the experiments.
